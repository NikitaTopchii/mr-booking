# Specification Compliance Matrix

This is the authoritative Phase 4A review matrix for the original three-page
UA-SKILLS specification. A row is `COMPLETE` only when implementation and
executed evidence exist. Allowed statuses are `COMPLETE`, `PARTIAL`, `MISSING`,
`INCORRECT`, `UNVERIFIED`, and `NOT_APPLICABLE`.

Evidence commands used for this audit include `yarn verify:commit`,
`yarn test:integration`, `yarn test:e2e`, `npm test`,
`docker compose config --quiet`, the clean tracked-file verification described
below, and the named focused suites.
